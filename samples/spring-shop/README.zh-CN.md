# Spring Shop 示例

[English](README.md) · [项目主页](../../README.zh-CN.md)

Spring Shop 是用于体验 Idea Lite 的小型合成 Java 项目，只包含演示代码和数据。

在 Idea Lite 中打开此目录。**连按两次 Shift** 搜索 `OrderService`，**Ctrl+单击** `findById` 的引用跳到定义，也可以在 **Maven** 和**服务**（Alt+8）工具窗口查看项目信息。运行 Maven 任务需要 JDK 17 或更高版本及 Maven。

如需体验 Git，请在仓库根目录运行 [`New-DemoWorkspace.ps1`](../../scripts/New-DemoWorkspace.ps1)。脚本会创建独立的本地仓库，包含合并历史、暂存改动和工作区改动。
