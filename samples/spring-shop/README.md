# Spring Shop sample

A tiny, synthetic Java project for exploring Idea Lite. No real credentials or company code.

Open this folder in Idea Lite. Try **Shift twice** → `OrderService`, **Ctrl+click** → `findById`, and the **Spring / Maven** tab. Maven is only run when you explicitly choose a task; it requires your own JDK 17+ and Maven.

To try Git in an isolated copy, run `scripts/New-DemoWorkspace.ps1`. The script creates a local repository with sample history, a branch and uncommitted changes. It never touches your own repositories.
